# Contributing to Knotworking

Follow the [quick start](README.md#quick-start) with a local demo database.
Describe the change and how you verified it in your pull request. Include
screenshots for visible UI changes and migrations for schema changes.

Run `pnpm typecheck` and `pnpm test` before submitting changes. Use
`pnpm exec prettier --check <files>` to check formatting for files you changed.

Report security issues through the private channel in [SECURITY.md](SECURITY.md).
Use synthetic records and redact credentials when sharing diagnostic output.
